## Demo flow (7–10 minutes total)

1. **Intro** (30 seconds) — [Jacob] introduces Consumed with Greed, a top-down procedural dungeon crawler. Pitch: "A game where every coin collected increases your power, but every floor descended scales the danger."
2. **Core gameplay** (2–3 minutes) — [Jacob] Start a fresh run. Show movement using custom keybindings, clear a "Normal" room to show enemy AI pathfinding, and collect coins. Explain how the DungeonGenerator created this specific layout on the fly.
3. **Highlight moment** (1–2 minutes) — [Jacob] Navigate to a Weapon Shop or Mini-Game room. Show the interaction with the ItemPedestal, the scaling costs (price multipliers), and how purchasing an item (like the Sniper or Toxic Aura) immediately changes the gameplay feel. Make sure to show off new class of weapons, pause menu, room transitions, and most importantly the boss.
4. **Iteration story** (1–2 minutes) — [Jacob] changed the early "hardcoded" difficulty with the current floor-based attribute scaling.
5. **Postmortem highlight** (1 minute) — [Jacob] Win: Successfully implementing the procedural room-link logic (BFS distances). Change: I would refine the "Greed" aspect to include more risk-vs-reward mechanics, like items that trade health for damage.
6. **Q&A** (1–2 minutes) — audience questions about design decisions
