# Consumed With Greed
By Jacob Marison 

## Controls - Rebindable in Title Screen
- WASD: move
- IJKL: aim
- `F1`: toggle dungeon debug overlay 
- `Y`: generate new dungeon
- `Esc`: quit

## Run
<h3> From this Folder: </h3>
    python -m pip install -r requirements.txt </br>
    cd src</br>
    python main.py
