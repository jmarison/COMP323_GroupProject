# Consumed With Greed
By Jacob Marison 

## Controls - Rebindable in Title Screen
- WASD: move
- IJKL: aim
- `F1`: toggle dungeon debug overlay 
- `Y`: generate new dungeon
- `Esc`: quit

## Run
From this Folder:
    python3 pip install -r requirements.txt
    cd /src/
    python main.py
